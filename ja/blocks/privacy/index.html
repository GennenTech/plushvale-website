このポリシーでは、カナダ・オンタリオ州の GennenTech（GennenTech Software Corp.）が提供する Plushvale Blocks での情報の取り扱いについて説明します。ゲーム用のアカウントやサインインはありません。セーブデータはお使いの端末に保存されます。Google の広告・同意サービスと Apple の App Store は、以下のとおり情報を処理します。

カナダ事業会社法に基づいて設立された法人である GennenTech Software Corp. が、当社が取り扱う個人情報について責任を負います。郵送先：GennenTech Software Corp., PO Box 20055, Kingston RPO Taylor Kidd, ON, K7P 2T6, Canada。個人情報の保護の責任者は、プライバシー責任者です。プライバシーに関するご質問、ご依頼、苦情は、プライバシー責任者宛てに privacy@gennentech.com までお送りください。

アプリが端末に保存するもの

プレイを再開したり設定を保ったりできるよう、ゲームの進行状況と設定はお使いの端末に保存されます。これらのセーブデータを当社のゲームサーバーに送ることはありません。端末のバックアップにアプリのデータが残ったり、バックアップから復元されたりすることがあります。

アプリには、プレイヤーのアカウントのデータベースも、ゲームプレイ専用の分析サービスもありません。ただし、これは以下で説明する Google の広告に関する診断や測定を除外するものではありません。端末のバックアップには、Apple のバックアップ設定に従って、端末に保存されたアプリのデータが含まれることがあります。

Google の広告データと同意データ

無料版では、Google AdMob のインタースティシャル広告と、Google のユーザー向けメッセージ プラットフォーム（UMP）を使っています。これらのサービスは、次の情報を収集または処理することがあります。

  • 「おおよその位置情報」：IP アドレスと、そこから推定されるおおよその位置です。アプリが端末の正確な位置情報を求めることはありません。「ユーザーに紐付けられるデータ」に該当しますが、トラッキングには使いません。目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」、「アプリの機能」。
  • 「デバイスID」：アプリや端末に関連する識別子で、ユーザーに紐付けられることがあります（「ユーザーに紐付けられるデータ」）。アプリは App Tracking Transparency（トラッキングの許可）を求めず、これらの識別子をトラッキングに使いません。目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」。Google のパブリッシャー ファーストパーティ ID は無効にしています。
  • 「アプリ内の操作」（タップや動画の視聴など）と「広告データ」（表示された広告など）：どちらもユーザーに紐付けられることがありますが（「ユーザーに紐付けられるデータ」）、アプリはトラッキングに使いません。「アプリ内の操作」の目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」、「アプリの機能」。「広告データ」の目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」。
  • 「クラッシュデータ」：「ユーザーに紐付けられないデータ」に該当し、トラッキングにも使いません。目的：「アナリティクス」。「パフォーマンスデータ」：「ユーザーに紐付けられるデータ」に該当しますが、トラッキングには使いません。目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」、「アプリの機能」。「その他の診断データ」：「ユーザーに紐付けられないデータ」に該当し、トラッキングにも使いません。目的：「サードパーティ広告」、「デベロッパの広告やマーケティング」、「アナリティクス」。
  • 同意の状態とプライバシーの選択：プライバシーに関するメッセージと広告リクエストの管理に使います。

アプリのプライバシーマニフェストでは、トラッキングを行わないと申告しています。App Store のプライバシー情報は、アプリとその SDK に合わせて正確に保つ必要があります。Google はこれらの情報を、広告の配信と測定、不正の防止、診断、同意の管理など、上記の目的に使います。ゲーム用のアカウントがないからといって、広告データが匿名になるわけではありません。「製品のパーソナライズ」と「その他の目的」は、申告している目的に含まれていません。

当社が個人情報を共有する第三者は、このポリシーと Apple の App Review ガイドラインと同等以上の保護を提供しています。

情報を処理する理由と同意

当社は Google AdMob を使って、無料のゲームを広告で運営し、広告の配信を測定し、同じ広告の繰り返しを抑え、不正の防止に役立てています。アプリは Apple の App Tracking Transparency の許可を求めず、トラッキングのために広告識別子（IDFA）を読み取ることもありません。パーソナライズされていない広告をリクエストしています。Google UMP は、必要な場合に同意のメッセージと選択を管理します。広告リクエストは、Google から返される同意の状態に従います。パーソナライズされていない広告でも、識別子や端末のストレージが使われることがあります。Google のパブリッシャー ファーストパーティ ID は無効にしています。同意の仕組みで必要とされる場合は、設定 → その他 → プライバシー設定 で、選べるプライバシーの項目を確認できます。端末のセーブデータはゲームプレイのために、サポートへのお問い合わせはご依頼への対応のために使います。EU または英国のデータ保護法が適用される場合、法律で必要なときは同意に基づき、ゲームと購入した特典の提供に必要な処理は契約に基づき、サポートへの回答と問題の調査は正当な利益に基づき、法律で定められたプライバシーのご依頼は法的義務に基づいて処理します。

Google の SDK データ開示、パートナーのアプリに関する Google の説明、Google のプライバシー ポリシーもご覧ください。Google による広告の測定は、端末に保存されるゲームのセーブデータとは別のものです。

お客様の選択

同意の仕組みで必要とされる場合は、設定 → その他 → プライバシー設定 を開いて、Google が提供する選択を確認・変更できます。この項目は、UMP がプライバシーオプションを必要と判断したときに表示されます。表示されないからといって、情報が処理されていないわけではありません。フォームが開かない場合やお困りの場合は、プライバシー責任者（privacy@gennentech.com）までメールでご連絡ください。同意を変更しても、それまでに適法に行われた処理が取り消されるわけではありません。

任意の1回限りの購入「ゲームを購入」で、広告が表示されなくなります。購入が確認されると、アプリは新しい広告リクエストを止め、待機中の広告を消去します。これにより、Google がすでに保有している情報が消えるわけではありません。不適切な広告は、設定の「広告を報告」を使うか、support@gennentech.com までメールでお知らせください。詳しくはサポートをご覧ください。

Apple での購入

支払いと購入の記録は、Apple がApp Store とプライバシーに従って取り扱います。StoreKit は、アプリが有料の特典を有効にしたり復元したりできるよう、確認済みの取引と利用権の情報を提供します。購入状況は StoreKit から更新されます。当社は購入用のサーバーを運営しておらず、支払いカードの情報を受け取ることもありません。購入を復元すると有料の特典が戻りますが、削除したセーブデータは戻りません。

メールでお問い合わせいただくと、当社はお客様のメールアドレス、メッセージ、送られた添付ファイルを受け取ります。これらは、ご返信、問題の調査、プライバシーに関する苦情への対応に使います。当社のサポート用メールは Zoho が提供しており、Zoho が配信と保存のためにメッセージを処理します。サポートのご依頼と米国の州のプライバシーの権利に関するご依頼は、support@gennentech.com までお送りください。広告の報告は、その広告を調べるために Google と共有することがあります。広告を特定するのに必要な情報だけをお書きください。パスワードや支払いカードの情報は送らないでください。

保存期間と削除

端末のセーブデータは、プレイ中に上書きされるか、アプリと一緒に削除されるまで端末に残ります。端末からアプリのデータを消すには、「アプリを取り除く」ではなく「アプリを削除」を選んでください。端末のバックアップに古いデータが残り、復元されることがあります。当社が端末のセーブファイルを遠隔で取り出したり消したりすることはできません。

サポートとのやり取りは、ご依頼への回答とその後の対応に必要な期間だけ保管し、その後削除します。プライバシーの連絡先から、早めの削除をご依頼いただくこともできます。Google と Apple のサービスにある情報の保存期間は、それぞれのプライバシーに関する通知に従って両社が管理します。このアプリを削除しても、両社の記録や App Store での購入は消えません。
