お問い合わせは support@gennentech.com までお送りください。担当者が返信します。アプリの名前とバージョン、iPhoneの機種、iOSのバージョンを添えて、何が起きたかをお知らせください。パスワードや支払い用カードの情報は送らないでください。

開発元について

Plushvale Blocksは、カナダのオンタリオ州にある小さなスタジオ、GennenTech（GennenTech Software Corp.）が制作しています。郵送先：GennenTech Software Corp., PO Box 20055, Kingston RPO Taylor Kidd, ON, K7P 2T6, Canada。ゲームに関するお問い合わせは support@gennentech.com、個人情報に関するご依頼はプライバシー責任者（privacy@gennentech.com）までお寄せください。

配信状況は国や地域によって異なります。お住まいの地域のApp Storeでご確認ください。

どうやって遊びますか？

フェルトのピースをドラッグして盤面に置きます。縦か横の一列が埋まると、その列が消えて、新しいピースを置く場所ができます。

  • 「クラシック」では、少しずつ難しくなる盤面でスコアを伸ばします。
  • 「ブリッツ」では、カウントダウンが終わるまでに列を消します。
  • 「パズル」では、決められた数のピースで盤面をすべて消します。時間制限なしで遊ぶには、「設定」で「リラックスパズル」をオンにしてください。
  • 「デイリー」では、その日のパズルに挑戦します。成績に反映されるのは初回の挑戦だけです。

「設定」で「遊び方」をタップすると、短いガイドを見られます。

「ゲームを購入」すると何が変わりますか？

「ホーム」で「ゲームを購入」をタップします。買い切りなので、支払いは一度だけです。サブスクリプションではありません。購入すると広告が表示されなくなり、1ゲームにつき「クラシック」では5回、「ブリッツ」では3回コンティニューできます。「パズル」ではレベル3の先に進み、レベル4〜8を遊べます。購入してもレベルを飛ばすことはできません。「パズル」と「デイリー」にはコンティニューはありません。詳しくはライセンスと購入について（英語）をご覧ください。

購入を復元するには？

インターネットに接続し、購入時に使ったApple Accountでサインインしてください。「ホーム」で「ゲームを購入」を開き、「購入を復元」を選びます。アプリがApp Storeに購入内容を照会して、購入特典を確認します。削除したゲームの進行状況は復元されません。

購入や復元がうまくいかないときは？

購入にも復元にもインターネット接続が必要です。アプリからApp Storeに接続できない場合は、接続状況を確認してから、もう一度お試しください。「承認と購入のリクエスト」で承認待ちになっている場合は、承認されるまでお待ちください。それでもうまくいかない場合は、アプリに表示されたメッセージをメールでお知らせください。

返金について

App Storeで購入した商品の返金はAppleが受け付けています。reportaproblem.apple.com からご申請ください。返金の可否は、この手続きの中で、お客様に適用される法律に基づいて決まります。開発元から直接返金することはできません。

プライバシーに関する選択を変更するには？

「設定」→「その他」→「プライバシー設定」の順にタップすると、Googleのフォームが再び開き、選択できる項目の確認や変更ができます。「プライバシー設定」は、Googleの同意管理システム（UMP）がこの項目を必要と判断した場合に表示されます。項目が表示されない場合でも、情報が処理されることがあります。

このアプリは、Appleのトラッキング許可を求めず、パーソナライズされていない広告をリクエストします。GoogleのパブリッシャーのファーストパーティIDは無効にしています。このリリースでは、子どもであると分かっているユーザーにはパーソナライズ広告の配信もトラッキングも行わないものとし、法律に沿った制限付きの広告配信を確保できない場合は広告を表示しないものとします。

フォームが開かない場合は、プライバシー責任者（privacy@gennentech.com）までご連絡ください。取り扱うデータや保存期間、お客様の権利、連絡先については、プライバシーポリシーをご覧ください。

広告を報告するには？

「設定」の「その他」から「広告を報告」を選ぶか、support@gennentech.com までメールをお送りください。広告を見たおおよその時刻、広告主の名前（表示されていた場合）、どの点が不適切だったか、または誤解を招くと感じたかをお知らせください。スクリーンショットがあれば調査に役立ちます。送る前に個人情報を取り除いてください。広告をタップする必要はありません。いただいた内容をもとに、Googleと調査を進めることができます。アプリはGoogleの広告コンテンツのレーティングが「G」の広告をリクエストしています。不適切だと感じる広告があればご報告ください。

ゲームの進行状況をリセットするには？

「アプリを削除」を選んでから、ゲームをインストールし直してください。「アプリを取り除く」を選ぶと、データは残ります。アプリを削除すると、端末に保存されている進行状況と設定が消えます。端末のバックアップを復元すると、以前の進行状況が戻ることがあります。アプリを削除しても購入は有効です。再インストール後に「購入を復元」をタップしてください。
